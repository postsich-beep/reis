# reis-archive — закритий архів версій «Рейсу»

Окремий **приватний** репозиторій. Сценарій `.github/workflows/archive.yml` раз на 3 години забирає кожну нову
версію з публічного `postsich-beep/reis` (APK, web.zip, version.json, вихідний код, контрольні суми) і зберігає
її тут як реліз. Ключів і паролів не потребує.

Друга копія — у самому `reis`: кожна збірка кладе чернетку «Архів · Рейс …» (бачить лише власник).

Повернути робочу версію на телефони: у `reis` → Actions → «Відновити версію з архіву» → Run workflow → версія.
